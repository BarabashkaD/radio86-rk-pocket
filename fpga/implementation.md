# fpga/: deviations from the original board

Where the Pocket core differs from the Radio-86RK board (Радио 1986) and Sergey Kiselev's re-make 1.4. The machine itself (`rk86_machine16` and the chip models) is in the libraries and follows the data sheets and the boards; its own notes are there. IDs follow retroICs' `docs/record-ids.md` (`RKPOCKET-DEV-n`); an ID keeps its number for good.

| ID | Statement | Basis |
|---|---|---|
| RKPOCKET-DEV-1 | An image of 65537 to 8388608 bytes is a J6 bank card: 128 banks of 64 KB, ROM address `{bank, PC7..PC0, PB}` on the second 8255 (A000-BFFF). | Not original hardware: a new card for J6 of Kiselev 1.4, a reference design never built ([../hardware/j6-bank-card.md](../hardware/j6-bank-card.md)). The core models the card's rule (`rtl/pocket_cart_ppi.v`), not its circuit. |
| RKPOCKET-DEV-2 | The bank latch takes PB0-PB6 (PB7 ignored) when PC7 falls and PC0-PC6 are all high after the fall; one `clk_74a` tick, only while the image is a bank card. The bank cannot be read back. | The card's rule (reference design): the monitor's `R` (FA68) never makes this event, so old software sees a plain 64 KB ROM. J6 carries only the port lines. |
| RKPOCKET-DEV-3 | The bank is cleared by the card reset only (power-up, a slot load, Core Settings > Cold boot); Core Settings > Reset keeps it. | J6 has no reset line; the reference design clears the bank at power-on. A slot load stands for plugging in a new card. |
| RKPOCKET-DEV-4 | The image size picks the card: up to 32768 bytes a 32 KB ROM, up to 65536 a 64 KB ROM (PC7 = A15), above it the J6 bank card. Port A carries the ROM byte always (no output enable); with no image it reads FF. | Pocket emulation by size, not card limits. On a real board the card that is plugged in decides. |
| RKPOCKET-DEV-5 | The ROM disk image is in the Pocket's PSRAM (`cram0`, `rtl/pocket_psram.v`), not in a ROM. No fill: beyond a shorter image port A reads whatever the PSRAM holds. | The Pocket's memory; block RAM is too small for 8 MB. The read latency (at most 24 clk) stays below the 8080's shortest port write to port A read (at least 167 clk). |
| RKPOCKET-DEV-6 | A 32 KB image: A15 not wired, so 8000-FFFF mirror 0000-7FFF (port C `PC6..PC0` and port B only). | The maintainer's decision (0.9.0). On Kiselev's card PC7 enables the ROM and port A reads FF while it is high. |
| RKPOCKET-DEV-7 | The screen is a 408 x 300 display window of the native raster (dots `X0` = 42 to 449, lines 0-299): text columns 6-73 of 78. The analogue video mixer and the CRT are not reproduced. | The Pocket's screen and its 34:25 aspect (`rtl/pocket_window.v`, `rtl/pocket_raster.v`). The machine ends at dots, HRTC and VRTC. |
| RKPOCKET-DEV-8 | Two frame banks between the 50 Hz machine and the 60 Hz output: a finished frame is shown at the next output frame start, about 25 picture updates per second. | The Pocket's display runs at 60 Hz (`rtl/pocket_frame_video.v`); the board drove the CRT directly at 50 Hz. |
