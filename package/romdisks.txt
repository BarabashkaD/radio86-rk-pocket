Radio-86RK ROM disks

The ROM disk is a 32 KB memory on the ports of the Radio-86RK's second 8255 (the
A000-BFFF block). At start the core loads romdisk.bin from this folder.

Run a program from the ROM disk
1. Open the on-screen keyboard with L+R (D-pad selects a key, B presses it, X is CR).
2. At the prompt -->, type R0,1FF,0 and press CR: the monitor copies the menu
   loader from the ROM disk to address 0000.
3. Type G0 and press CR: the menu appears.
4. Press the key of the program. Close the keyboard with L+R to see the whole screen.

Change the ROM disk
- While the core runs: open the Pocket menu (the Analogue button), load the
  "ROM disk" slot again and pick a .bin file of this folder (up to 32768 bytes).
  The Pocket holds the machine in reset while it loads the file, then the machine
  restarts as after Core Settings > Reset: the memory is kept. Type R0,1FF,0 and
  G0 again for the new disk's menu.
- At the next start the core loads romdisk.bin again. To start with another disk,
  keep romdisk.bin under another name and copy the other disk here as romdisk.bin.

romdisk.bin: ROM-DISK/32K V3.0-2020 by Sergey Kiselev (GPL-3.0)
  0  BASIC
  1  EDITOR/ASSEMBLER
  2  EDITOR/DISASSEMBLER
  3  DP/DDT
  4  XONIX
  5  OTHELLO
  6  TETRIS
  S  copy the editor to the temporary buffer
  L  copy the temporary buffer to the editor
  Z  clear the memory
Programs 3 (DP/DDT) and 4 (Xonix) overwrite the menu loader, as on the real
machine: use Core Settings > Reset, then R0,1FF,0 and G0 again.
Tetris asks for a level (0-7), then plays with 7 (left), 8 (rotate), 9 (right),
6 (faster) and Space (drop); S pauses. Core Settings > Keys = Digits 7-8-9-6
puts them on the D-pad, with Space on A.
