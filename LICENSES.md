The package's `Cores/BarabashkaD.Radio86RK/` holds `LICENSE.txt`, `LICENSE-tselikov-bsd.txt`, `NOTICE-retro.txt` and `APF-NOTICE.txt`; the package carries no ROM disk image and no `LICENSE-romdisk.txt`. `LICENSE.txt` is this repository's `LICENSE`; `LICENSE-tselikov-bsd.txt` is retroICs' `LICENSES/LicenseRef-Tselikov-BSD.txt` (the 8257 and 8275 models); `NOTICE-retro.txt` holds the `NOTICE` files of retroMachines and retroICs as they are (`scripts/package.py`, `notice_text`); `APF-NOTICE.txt` is the template's notice. Up to 0.9.0 the package held `LICENSE-karabas-core.txt` (the Karabas fork's `src/LICENSE.TXT`) in place of `LICENSE-tselikov-bsd.txt` and `NOTICE-retro.txt`. A release attaches `romdisk-LICENSE.txt` (Kiselev's GPL-3.0 text: his ROM disk inside `card.bin`, four programs from it in `fatcard.bin`, the game disks' menu loader derived from his), and its notes link Kiselev's `rom_disk.bin` at `c5e9cb7` and this repository's source commit. The programs on Kiselev's disk and the game tapes are binaries without sources or stated terms: an open item (above). The CC BY 3.0 attribution of the 8080 model is the Credits line of `info.txt`.

GPL-3.0 and CC BY 3.0: not combined, aggregate distribution. Since 0.9.0 no GPL-3.0 file is in the bitstream or the package: the bitstream holds the CC BY 3.0 8080 model with BSD-style code only. The GPL-3.0 code (the games menu loader, Kiselev's ROM disk and the programs taken from it) is only in the separate release images (the game disks, `card.bin`, `fatcard.bin`), which the core reads at run time from a data slot as data; each image goes with `romdisk-LICENSE.txt` and the source links of the release notes.
